# Sharing-image fonts

Unmodified regular faces, bundled only for build-time Takumi rendering. Website
font loading remains in `src/shared/styles/global.css`. These source files are
not placed in `public` or served to visitors.

- **Fira Sans**: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/firasans),
  `FiraSans-Regular.ttf`. License: `FiraSans-OFL.txt`.
- **Libertinus Math**: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/libertinusmath),
  `LibertinusMath-Regular.ttf`. License: `LibertinusMath-OFL.txt`.
- **MaruBuri**: [Naver's official distribution](https://hangeul.naver.com/font),
  `MaruBuri-Regular.ttf` from `MaruBuriTTF.zip` inside
  [maruburi.zip](https://hangeul.naver.com/hangeul_static/webfont/zips/maruburi.zip).
  License: `MaruBuri-OFL.txt`, with Naver's copyright notice and SIL OFL 1.1
  as specified in [Naver's license notice](https://help.naver.com/service/30016/contents/18088?osType=PC&lang=ko).

corresponding license files when redistributing these fonts.
